จัดการเว็บ Thai Mod

เพิ่ม แก้ไข ลบ และเรียงลำดับเกม แล้วกด "บันทึกขึ้นเว็บ" เว็บจริงจะอัปเดตภายในประมาณ 1 นาที

รหัสเข้าถึง GitHub (token)

ยังไม่ได้ใส่ token

วิธีสร้าง token (ทำครั้งเดียว)
  1. เข้า GitHub แล้วไปที่ Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token
  2. ตั้งชื่อ เช่น thai-mod-admin และเลือกวันหมดอายุตามต้องการ
  3. Repository access: เลือก Only select repositories แล้วเลือก thai-mod เท่านั้น
  4. Permissions > Repository permissions: ตั้ง Contents เป็น Read and write
  5. กด Generate token แล้วคัดลอกมาวางในช่องด้านบน

token จะถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกส่งไปที่อื่นนอกจาก GitHub ถ้าใช้เครื่องสาธารณะ ให้กด "ลืม token" หลังใช้งาน

ใส่ token เพื่อเริ่มต้น
